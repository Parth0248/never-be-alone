## 🎬 Best Practices for Demo Recording

### For Audio Quality:
1. Speak clearly and at a moderate pace
2. Mention specific dates, times, names, and details
3. Ask questions that require reasoning
4. Include action items and requests
5. Use natural conversational language

### For Image Quality:
1. Good lighting - avoid dark/blurry images
2. Center the subject in frame
3. Include text when relevant (signs, labels, screens)
4. Show context (not just close-ups)
5. Capture 2-4 key images per scenario

### For Maximum Impact:
1. **Show progression**: Before → Processing → After
2. **Highlight responses**: Display what was sent to OMI app
3. **Show memory retrieval**: Ask follow-up questions using past context
4. **Demonstrate intelligence**: Don't just transcribe, show understanding
5. **Show all 5 integrations**: Omi → Reka → ASI:One → Supermemory → OMI App

### To Showcase Reka.AI:
- Use scenarios with BOTH images and complex audio

- Demonstrate contextual reasoning

- Use task extraction scenarios
- Show agentic behavior (planning, scheduling)
- Demonstrate multi-step reasoning

### To Showcase Supermemory:
- Reference past conversations

- Demonstrate context retrieval
